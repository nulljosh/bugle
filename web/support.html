Help with Bugle for iPhone and iPad

← Back to Bugle

Bugle is a multi-feed RSS and Atom reader. If something is not working, the fastest route to a fix is an issue on GitHub with the feed URL that is giving you trouble.

Report a bug or request a feature

Open an issue on the Bugle issue tracker. Including your iOS version, your device, and the exact feed URL involved makes a problem far quicker to reproduce and fix.

Adding a feed

Open the feed list, choose to manage feeds, and paste the address of the feed you want. Bugle accepts both RSS and Atom feeds. Most sites publish theirs at an address ending in /feed, /rss, or /feed.xml — if a site advertises its feed, that address is what Bugle needs.

A feed will not load

  • Check that the address points at the feed itself rather than the site's normal homepage. A homepage is HTML, not a feed, and cannot be parsed.
  • Open the same address in Safari. If it fails there too, the feed's own server is down or the address is wrong.
  • Some sites put their feed behind a login or a bot filter. Those feeds cannot be read by any standalone reader, Bugle included.

An article looks empty or incomplete

Bugle renders what the feed publishes. Many sites deliberately publish only a short summary rather than the full article, in which case opening the entry's original link is the only way to read the whole piece. If an article that does contain a full body renders blank, that is a bug worth reporting.

Reading offline

Entries are cached on your device as they are downloaded, so anything already pulled down stays readable without a connection. New entries still need a connection to fetch.

Removing the default feed

Bugle subscribes to one feed on first launch so that the app is not empty. Remove it from the manage-feeds screen the same way you would remove any other subscription.

Accounts and data

You never need an account to read. An optional one in Settings keeps your feed list the same on every device and the web reader, and you can delete it there at any time. See the privacy policy for exactly what it stores.

Still stuck

Open an issue on GitHub and describe what you expected to happen and what happened instead.
